# Personal Portfolio - GitHub Pages

This repository is set up as your GitHub Pages personal site.

## Current stack

- HTML: `index.html`
- CSS: `styles.css`
- JavaScript: `script.js`

## Edit your information

1. Update your name, bio, and section text in `index.html`.
2. Replace placeholder project cards in the Projects section.
3. Update contact links and email in the Contact section.
4. Adjust colors and typography in `styles.css` if you want a different look.

## Publish

Because this repository is named `alexruiz0.github.io`, GitHub Pages will serve it directly from the default branch root.

Site URL:

- https://alexruiz0.github.io
